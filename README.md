# RIN-framework

[Open the protein network tutorial](tutorial/Protein_Network_Analysis_AAV8.ipynb)
or read the [setup instructions](tutorial/README.md).

The tutorial includes Jonathan Zajac's lysozyme/thaumatin/apoferritin examples
and an AAV8 MD snapshot: single-VP structure, centrality-colored RIN views,
and the complete capsid. Download the full repository to keep the notebook
and its example data together. Data sources are listed in
[tutorial/SOURCES.md](tutorial/SOURCES.md).

This initial repository upload contains the tutorial and its data. The full
MD workflow and production analysis outputs are not part of this upload.
